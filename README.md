## 完整選單討論示範（v14.2）

- 新增營運活動 5 頁：活動中心、RTP 活動、免費旋轉、紅利／獎勵、活動紀錄。可建立／編輯草稿、選擇多遊戲與現金網、設定 UTC+8 期間與預算、啟停示例狀態並查看範圍。RTP 活動可跳轉遊戲 RTP 設定；活動本身不自動改動 RTP 或發放獎勵。

- 原投注與財務記錄不變；總盈利、總虧損與淨盈虧可核對。卡片、圖表及表格沿用綠色品牌與 #E6C066 輔助色。

- CMS 獎池規則可分開設定初始金額、初始投入比例及收支分攤比例，試算同步顯示雙方投入與損益。設定變更保存在草稿與發布快照，不改寫歷史財務卡片，也不會執行實際入金。
- 現金網使用列表加入逐站啟動／關閉，只改動該遊戲／站點，保留其他站點、RTP 與已部署版本。原未部署站點啟動時使用目前建議版本；確認畫面會先顯示版本。單站同步獨立於全域總開關；全域下架、遊戲維護及站點維護仍優先。狀態與版本可跨重新整理保存並寫入審計。
- 系統管理含帳號、角色與權限矩陣、示例 API 金鑰、IPv4／IPv6／CIDR 白名單、48 筆 API 日誌、系統顯示偏好、同步及統一審計。帳號／角色／金鑰／IP 可新增、編輯；日誌與審計可即時搜尋、篩選及查看明細。時區、語言與明暗外觀接上既有工作區偏好。
- 子選單依帳號、金鑰、權限、網路、API、設定、同步及審計等功能使用不同原創線條圖示；遊戲與其他功能群組也改用對應圖示。移除重複的 CMS 流程提示，保留精簡同步狀態與操作入口。
- 以上均為瀏覽器內的互動示例，未連接正式帳號、API 金鑰／IP 驗證、現金網、獎池入金或帳務服務；既有歷史資料不變。系統測試資料使用保留的 `.test` 信箱及文件用途 IP 網段。
- 入口：`?v=14.1#jackpot/pools`、`?v=14.1#games/catalog`、`?v=14.1#system/accounts`。

## CMS 規則、發布與現金網同步（v14.0）

- 「遊戲管理 → 遊戲規則」可為每款遊戲新增、複製及編輯多套規則，設定 RTP 基準、單局投注／派彩限制、免費回合及各類玩法參數；捕魚固定提供五級子彈倍率。現金網個別 RTP 覆寫與排程仍優先，到期回復當時的規則基準；繼承預設的規則使用遊戲預設值。
- 「累積獎池 → 累積獎池規則」可設定實扣／有效投注提撥、預設比例與每筆上限、事件／投注／餘額觸發、門檻及冷卻、固定／獎池比例／投注倍率／沿用遊戲事件派彩、派彩上限、保留餘額及餘額不足政策。試算即時顯示提撥、派彩與餘額，不寫入歷史帳目。
- 草稿、不可變的已發布版本、CMS 現金網指定及現金網已套用快照分開保存。發布時逐站勾選、搜尋或全選；獎池可逐站設定比例、是否累積及中獎資格。未勾選現金網保留原版本；儲存草稿不影響任何站點。
- 「設定同步中心」顯示待同步、同步中、已套用、失敗與被新版取代；可只重試失敗站點。多站批次刻意模擬一次連線逾時，重試後成功。新批次會取代相同遊戲／站點／設定領域的未完成舊批次；較舊回覆不得覆蓋較新設定。回覆不增加內容修訂號，避免錯誤地使編輯視窗失效；跨分頁內容變更則阻止覆寫。
- 上下架、維護及既有 RTP 編輯也從 CMS 儲存並建立同步批次。全域下架／維護仍立即禁止新局，站點尚未收到快照也不得繞過總開關。現金網快照為唯讀；所有修改都回到 CMS。
- **此專案仍為瀏覽器內的互動 Demo**：規則與模擬回覆保存在同一個 localStorage 工作區，未連接正式 CMS API、現金網、遊戲伺服器或派彩帳本。正式服務須在服務端執行驗證、權限、版本發布與冪等派彩。原 2026-10-15 歷史投注及獎池資金保持不變。
- 入口：`?v=14.0#games/rules`、`?v=14.0#jackpot/rules`；沿用繁中、越南文、泰文及手機排版。

## 版本分布、現金網名單與累積獎池（v13.1）

- 版本頁按遊戲顯示三個示例版本及各自使用家數。點選版本可按包網商查看現金網名單；同時保留建議版本、已部署家數、舊版配置與未部署現金網資訊。部署配置與可遊玩狀態分開，遊戲全域下架後仍保留版本配置，但各版本的可遊玩家數歸零。
- 遊戲列表、上下架與維護頁的可遊玩家數可直接點擊，預設只顯示對應現金網，另可切換全部及不可遊玩名單。現金網連結可再進入機構詳情，並返回原名單或版本篩選。
- 累積獎池五頁已接上既有資料：列表、規則、參與遊戲、中獎紀錄及報表。沿用 2026-10-15 的 9 個示例共用獎池、79 筆中獎紀錄；期初 900,000.00＋累積 3,118.10－派彩 42,540.00＝期末 860,578.10 USDT。金額以整數分核對，不另造派彩資料。
- 獎池可往下查看遊戲、現金網、玩家與投注單，並返回上一層。中獎紀錄支援即時搜尋、獎池／類型篩選及分頁；依篩選結果重算中獎金額與去重玩家、現金網家數。
- 獎池報表提供每小時累積／派彩柱圖、派彩排行及資金流向。圖表支援 Hover／鍵盤提示、數列開關、資料展開與既有的 280ms 動畫；減少動態設定仍有效。關閉數列會重算顯示上限及顯示值，不會改動來源帳目。
- 提撥沿用每筆實扣投注的 2%，逐筆四捨五入至小數 2 位；提撥包含在投注內，不另行扣款。獎池派彩已包含於投注派彩，不可重複加總。觸發條件及規則版本沿用既有模擬資料，並未執行實際抽獎或派彩。
- v13.0 的全域上下架、現金網 RTP 覆寫／排程及時區偏好均保留；此次新增版本部署分布為唯讀的示例配置，不會發布正式遊戲版本。

## 遊戲管理與時區時間（v13.0）

- 右上角顯示每秒更新的日期、時間與 UTC 偏移；可從時鐘、帳號選單或「系統管理 → 系統設定」開啟時區設定，搜尋 IANA 時區或跟隨裝置。選擇只預覽，儲存才生效；偏好留在目前瀏覽器。夏令時間由時區規則處理。
- 報表與營運排程保持 UTC+8；時鐘的顯示時區獨立設定。
- 「遊戲管理」六頁：遊戲列表、遊戲分類、RTP 設定檔、遊戲上下架、版本管理、維護管理。涵蓋 18 款遊戲、18 家現金網與 6 家包網商。
- 上下架是遊戲全域總開關，優先於遊戲維護、現金網啟用／維護及 RTP 設定。確認前按包網商列出所有現金網及前後狀態，分開顯示本次新增受影響家數與全域控制範圍；重新上架保留原本的停用與維護限制。
- RTP 採遊戲預設＋現金網個別覆寫，可持續覆寫或指定開始／結束時間。開始時間包含、結束時間不包含；到期後恢復「當時的遊戲預設值」，不恢復較早的覆寫。新設定會取代同一現金網／遊戲原有的設定。
- 提供待生效、生效中、已到期與繼承預設狀態。全域下架仍保留 RTP 排程，但排程生效不能重新啟用遊戲。RTP 設定與歷史報表的實際返還率分開，既有投注明細不會被改寫。
- 上下架、維護與 RTP 異動保留前後值、現金網、時間、操作人及原因；跨分頁變更會要求重新確認。異動原因維持使用者原文，不隨介面語言替換。
- 這是瀏覽器內的互動規劃示範，未連接正式遊戲服務；實際停用、進行中回合／未結算訂單處置、核准 RTP 範圍及排程執行需由正式後端實作。版本頁提供發布流程規劃與示例資料，不執行正式發布。

## 可操作內容

- 品牌輔助金色 #E6C066 用於次要操作、匯出、新增分頁、日期圖示、資訊卡圖示、圖表標題、熱門遊戲主要佔比及詳情入口；一般資訊數值統一白色（亮色模式使用對應深色），盈利維持綠色、虧損維持紅色。表格 Hover 為較暗藍綠色 #202C28，與綠底合計列分開。
- 所有圖表共用即時詳情提示：曲線按滑鼠所在時段顯示時間、數值與記錄筆數，圓環分段和圖例顯示遊戲、數值與佔比；排行、詳情中的每小時長條及遊戲佔比也支援。提示使用液態玻璃底板，支援 Hover、鍵盤焦點／左右切換、手機點選，並隨篩選更新。
- 圖表區域使用一般箭頭游標；可操作的圖例使用手形。曲線與圓環圖例可點擊圓點或文字開關，關閉狀態淡化並加刪除線，各工作分頁分別保留顯示設定；圓環依開啟的圖例重新計算佔比、遊戲數及筆數／投注額，並標示目前顯示範圍；上方營運指標維持整體篩選結果。圖表以兩列對齊，窄畫面改為單欄；視覺／表格切換按鈕的 Icon 與文字保留 10px 間距。
- 「重設」使用品牌輔助金色邊框、淡底色與光暈，文字維持一般前景色；「即時篩選」狀態維持綠色。
- 曲線圖與圓環圖的所有圖例共用左右 12px、上下 6px 留白，Hover 底色與內容邊緣保持一致距離。
- 圖表展開的資料表以相同欄位規則呈現表頭、合計與明細：時間靠左、數字靠右，左右留白統一 16px；共用明細表的數字表頭也遵循同一對齊規則。

- 導覽採緊湊排列：Logo 108px、主選單最小寬 120px、左右留白 6px、項目與圖文間距 4px；子選單左右留白 16px，選中底板、標題和關閉按鈕均保留對稱外側留白。兩層選單依目前內容、語言和實際字型自動計算寬度；子選單通常為 220–340px，窄畫面依可用空間限制寬度。切換選單或語言會重新計算，主內容隨之平順延伸。

- 儀表板與品牌 Logo 直接返回營運總覽，首頁呈現共用模擬資料的玩家曲線、遊戲佔比及營運排行；首次進入只開啟首頁。
- Header 提供圖示式「關閉所有分頁」，關閉工作分頁後返回首頁，並清除待處理搜尋。
- 所有單選下拉選單使用統一深灰玻璃清單，包含日期快捷、幣別、進階條件、每頁筆數與凍結欄數；支援方向鍵、Home／End、Enter、Escape 及文字尋找。複選維持原有可搜尋清單。

- 子選單與主畫面共用 240ms 的展開／收合節奏；主畫面會平順填滿或讓出空間，可快速反向操作。
- 包網商、商戶／站點、遊戲類型／玩法及遊戲名稱支援可搜尋複選；同欄採 OR、跨欄採 AND，勾選即篩選。包網商或玩法變更時保留相容的站點與遊戲，移除不相容選擇。

- Header 工作分頁可新增、同頁多開、切換、關閉。每個分頁獨立保存查詢、排序、頁碼、欄位及捲動位置，重新載入可恢復。

- 包網商與現金網連動，切換後清除不相容站點；遊戲類型、名稱與捕魚房間也保留相容選擇。摘要、合計、分頁與 CSV 使用同一組即時結果。
- 凍結邊界使用單一連續陰影，涵蓋表頭、合計及可見資料列；取消凍結或沒有可捲動欄位時隱藏。
- 表格橫向／縱向捲動、排序、分頁、欄位顯示與順序設定、凍結左側欄位、CSV 匯出。
- 表頭漏斗支援欄內搜尋、多選、金額／數量與時間範圍，右鍵也能開啟。變更即更新背景報表，面板維持開啟；「完成」只關閉面板。無效日期或反向範圍保留上次有效結果並顯示錯誤。
- 可凍結至任一目前顯示的欄位，亦可取消；欄位重排後依顯示順序處理，窄畫面保留未凍結的捲動區。篩選標籤可返回編輯、單欄清除或全部清除。

- 捕魚明細包含 100／60 發逐發射擊、魚隻實例 ID、道具、首領事件、獎金及資金對帳。
- 電子遊戲逐關歷程與自主收取／失敗案例；老虎機父子旋轉與派彩拆分；21 點、牛牛、鬥地主的各自明細。
- 點擊玩家帳號／ID 可查看各遊戲盈虧、最近遊玩與投注額排行；遊戲卡片及投注單號可繼續往下開啟明細。

- 統一 40px 篩選控制項與上下共用的 1–7 欄網格（按主畫面可用寬度自動調整，包含選單展開／收合）；日期標籤統一在上方，快捷下拉選單與區間按鈕各佔一欄，與其他欄位共用網格；同一天只顯示一次，窄欄位的跨日區間以月日顯示、年份標示在上方，完整區間保留於提示與日期選擇器；下拉箭頭和文字保留對稱留白。日期區間使用錨定日曆元件，不遮住整頁。表頭與資料不強制換行，欄位過多可橫向捲動；工作分頁超長提供全文提示。

- 遊戲統計預設視覺總覽：去重玩家曲線、遊玩筆數／投注額佔比圓環圖、投注／派彩趨勢、遊戲營運排行，可切換傳統表格。曲線為有投注記錄的玩家，並非即時在線人數。

## 逐層詳情與視覺切換

從報表工具列的「機構總覽」，或供應商／站點欄位，可依序查看 **遊戲商 → 包網商 → 現金網 → 玩家 → 遊戲 → 投注明細**。機構層級以可點擊的圖示關係卡片連接，每層保留返回上一層，移除重複的詳情標題，機構與玩家可切換「視覺摘要／傳統表格」，金額與範圍一致。

- 六個包網商、18 個現金網、132 位玩家；每位玩家只屬於一個現金網，逐層加總不重複。
- 18 款虛構遊戲：4 款電子闖關、5 款老虎機、3 款捕魚及 6 款棋牌。相同家族共用示範規則與六張分類封面，正方形、12px 圓角；卡片呈現投注佔比、玩家盈虧與獎池派彩。
- 時段圖依記錄的每小時投注額計算，並非隨機製造的 KPI。尚無登入、註冊、留存等資料，因此不顯示這些指標。
- 投注派彩差額＝投注−派彩，未扣分潤與營運費用，不能當成機構實際收益。
- 篩選標籤與輸入框相距 6px，控制項維持 40px；長字保留換行或全文提示。

## 子彈費率與獎池口徑

捕魚同一批次包含 Lv.1 至 Lv.5 五級子彈，逐發保存基礎面額、炮倍、當時費率、實扣金額、來源及扣款 ID，並記錄級距切換後首發 ID。以原始 F001 為例：30×1＋20×1.5＋10×2＋20×3＋10×4＝180 USDT，再加一次道具費 20＝200；10 發免費彈的參考面值 40 不計入投注。

九款遊戲示範可配置獎池，九款未配置。獎池有 ID、級別、規則版本、觸發來源、父事件、提撥、前後餘額、獎金、交易及入帳狀態；區分未配置、未觸發、已入帳。示範提撥率為 2%，已含在投注內，並非額外扣款。一般派彩與獎池派彩分列，總派彩只算一次。費率、獎池門檻與棋牌特殊規則均為 **Demo 規則提案**，正式規則以供應商 API 為準。

## 本機預覽與驗證

    npm start

開啟 http://127.0.0.1:4173/。也可以使用任意靜態 HTTP server。

    npm test

測試涵蓋七種報表金額一致性、玩家 ID 關聯、合計與去重、篩選、空資料、逐發成本／獎金、錢包餘額、CSV 精度、數值排序、語系欄位完整性與舊分頁設定轉換。

    npm run build:data

可由保留的 21 筆種子資料，重建相同的 1,200 筆模擬記錄；原始 400 筆的金額、玩家與站點不變。

## GitHub Pages

在 GitHub 的 **Settings → Pages** 選擇 **Deploy from a branch → main → / (root)**。後續更新 main 即會重新部署。

所有頁面使用 hash 路由，例如 /#fishing、/#slots、/#stats，重新整理不需要額外的伺服器路由設定。
