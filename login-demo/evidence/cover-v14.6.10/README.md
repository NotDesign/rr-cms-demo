# v14.6.10 第一張滿版恢復

2026-11-11。使用者指出 v14.6.9 將第一張三人側臉背景縮小，破壞原本的滿版構圖。

## 修正

`scene-config.js` 分別指定 `cover` 與 `subject-fit`。第一張恢復原有 `object-fit: cover; object-position: left center`，填滿背景容器，移除第一張的邊緣遮罩與柔焦延伸。第二張繼續用角色範圍計算等比例縮放。平板與手機仍採上圖下表單；第一張填滿上方圖片區域。這次沒有修改圖片內容、WebP、粒子或閃電。

## 驗證

- 230 項 Node 測試通過；既有構圖計算測試改為針對使用 subject-fit 的傳送門背景。
- Brave 檢查 1823×1247、1440×900、834×1112、390×844。第一張圖片框與背景容器完全一致，cover／靠左置中／無圖片遮罩均符合；第一張允許原有滿版裁切。
- 第二張圖片均載入，角色範圍與登入卡片不相交；1440×900 實際切換檢視第二張。
- 上述視窗皆無水平溢出或主控台錯誤。詳見 `responsive.json`。未宣稱實機 Safari／Firefox 驗證。
