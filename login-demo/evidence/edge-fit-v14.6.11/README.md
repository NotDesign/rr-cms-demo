# v14.6.11 傳送門上下留白修正

2026-11-11。使用者截圖顯示第二張背景仍有過多上下留白。

## 修改

- 桌機卡片寬度由最大 512px 收窄至最大 400px，最小 360px；右邊距改為 32px，釋出角色圖片可用寬度。
- 傳送門使用完整視窗高度，不額外扣除上下 96px；圖片角色範圍與卡片保留至少 16px。原圖保持等比例，不拉伸人物。
- 桌機傳送門圖片頂部淡入 1.5%，底部最後 6% 淡出，縮短原本 3%／16% 的羽化範圍。
- 第一張繼續滿版 cover；小於 1100px 的圖片與表單排列不改動。WebP、圖片內容、綠色粒子與閃電不變。

## 驗證

- 231 項 Node 測試通過，新增使用者截圖比例 1820×1187 的邊界案例。
- Brave 1820×1187：傳送門圖片高 1135.52px，上邊距 25.73px、下邊距 25.74px，與卡片距離 16.00px；完整角色範圍不與表單相交。
- 依 v14.6.10 的構圖公式，在相同視窗推算圖片高度約 948px；本版放大約 20%。舊版數值為公式比較，不是另一次瀏覽器量測。
- Brave 1366×768：圖片使用完整 768px 高度，與卡片距離約 19.81px；也切換第一張檢查滿版效果。
- Brave 834×1112、390×844：維持上圖下表單，無水平溢出。全部觀察中兩張圖片載入，主控台無錯誤。詳見 `responsive.json`。
- 手機與平板報告座標隨頁面捲動，與桌機一樣都使用同一視窗座標系計算相交。未宣稱實機 Safari／Firefox 驗證。
