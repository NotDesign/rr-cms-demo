# R&R CMS HTML Demo

以 R&R BackOffice Figma 定版風格製作的靜態互動示範。預設繁體中文，所有金額為 **USDT**，無需安裝前端依賴即可放到 GitHub Pages。

## 可操作內容

- 品牌輔助金色 #E6C066 用於匯出操作、模擬資料標籤、部分資訊圖示與圖表；表格 Hover 為較暗藍綠色 #202C28，與綠底合計列分開。

- 導覽採緊湊排列：Logo 108px、主選單最小寬 120px、左右留白 6px、項目與圖文間距 4px；子選單左右留白 16px，選中底板、標題和關閉按鈕均保留對稱外側留白。兩層選單依目前內容、語言和實際字型自動計算寬度；子選單通常為 220–340px，窄畫面依可用空間限制寬度。切換選單或語言會重新計算，主內容隨之平順延伸。

- 儀表板與品牌 Logo 直接返回營運總覽，首頁呈現共用模擬資料的玩家曲線、遊戲佔比及營運排行；首次進入只開啟首頁。
- Header 提供圖示式「關閉所有分頁」，關閉工作分頁後返回首頁，並清除待處理搜尋。
- 所有單選下拉選單使用統一深灰玻璃清單，包含日期快捷、幣別、進階條件、每頁筆數與凍結欄數；支援方向鍵、Home／End、Enter、Escape 及文字尋找。複選維持原有可搜尋清單。
- 資料助理改用 CS 耳機圖示，語言箭頭使用 16px 細線 chevron；瀏覽器 favicon 使用獨立品牌符號。

- 子選單與主畫面共用 240ms 的展開／收合節奏；主畫面會平順填滿或讓出空間，可快速反向操作。
- 包網商、商戶／站點、遊戲類型／玩法及遊戲名稱支援可搜尋複選；同欄採 OR、跨欄採 AND，勾選即篩選。包網商或玩法變更時保留相容的站點與遊戲，移除不相容選擇。
- 日期快捷、日期區間與所有篩選欄位共用同一套欄線，每個控制項佔一欄並對齊上下邊界。報表標題與凍結提示之間縮至約 12px。
- 詳情、日期、欄位操作、複選、語言選單與資料助理統一使用較明顯的玻璃底版；內容卡片保留清晰底色。
- 玩家詳情新增所屬代理、註冊地區／時間／IP／裝置、VPN／代理 IP、ISP、上次登入時間／IP／裝置。來源及登入資料均為穩定生成的模擬值，IP 使用文件示例網段。
- 右下角資料助理支援玩家 ID、投注單、遊戲、機構查找，以及目前篩選的投注、派彩、盈虧、玩家排行和獎池摘要；回答可直接開啟詳情。此版依 Demo 資料做檢索與計算。

- 九個主選單，右側子選單展開／收合。系統管理依正常順序排列，語系切換固定底部。
- 七種遊戲報表：所有遊戲、電子遊戲、老虎機、捕魚、棋牌、玩家遊戲記錄、遊戲統計。
- Header 工作分頁可新增、同頁多開、切換、關閉。每個分頁獨立保存查詢、排序、頁碼、欄位及捲動位置，重新載入可恢復。
- 七張報表均有玩家 ID；遊戲統計提供去重 ID 清單並保留彙總層級。帳號與 ID 可開啟玩家詳情。
- 日期、包網商、現金網、遊戲、玩家、ID、類型與事件選擇後自動篩選；文字停止輸入 350ms 後更新，保留游標與焦點。工作分頁的待處理搜尋互相隔離，重設會清除待處理條件。
- 日期快捷：今天、昨天、近一週（含今天 7 天）、近一月（含今天 30 天）、上個月（完整曆月），一律按 UTC+8 計算並即時篩選；保留模擬資料日快捷。
- 包網商與現金網連動，切換後清除不相容站點；遊戲類型、名稱與捕魚房間也保留相容選擇。摘要、合計、分頁與 CSV 使用同一組即時結果。
- 凍結邊界使用單一連續陰影，涵蓋表頭、合計及可見資料列；取消凍結或沒有可捲動欄位時隱藏。
- 表格橫向／縱向捲動、排序、分頁、欄位顯示與順序設定、凍結左側欄位、CSV 匯出。
- 表頭漏斗支援欄內搜尋、多選、金額／數量與時間範圍，右鍵也能開啟。變更即更新背景報表，面板維持開啟；「完成」只關閉面板。無效日期或反向範圍保留上次有效結果並顯示錯誤。
- 可凍結至任一目前顯示的欄位，亦可取消；欄位重排後依顯示順序處理，窄畫面保留未凍結的捲動區。篩選標籤可返回編輯、單欄清除或全部清除。
- 主選單與子選單保留深灰色玻璃底，Active 使用品牌綠與下方柔和光暈；Hover 使用偏藍綠。外圍不描邊，主選單陰影疊在子選單上，子選單陰影疊在內容上。主選單後方 560／640px 品牌綠光團以 100／115px Blur、38／46 秒交替流動；子選單以 70% 尺寸、較淡薄荷綠及 44／52 秒獨立節奏折射相同光源，並加強玻璃柔化程度；上方維持深灰，下方呈現較明顯的透光效果。Active 為上灰下綠並帶底部光暈，Hover 為灰色提亮。使用提供的原始 SVG，Logo 寬 108px。
- 捕魚明細包含 100／60 發逐發射擊、魚隻實例 ID、道具、首領事件、獎金及資金對帳。
- 電子遊戲逐關歷程與自主收取／失敗案例；老虎機父子旋轉與派彩拆分；21 點、牛牛、鬥地主的各自明細。
- 點擊玩家帳號／ID 可查看各遊戲盈虧、最近遊玩與投注額排行；遊戲卡片及投注單號可繼續往下開啟明細。
- 棋牌案例涵蓋 21 點勝負、和局、自然 21 點、加倍、分牌、保險；牛牛牌型勝負與和局；鬥地主炸彈及春天。
- 繁體中文、越南文（VN）、泰文切換，並記住語言。簡譯區分實扣投注、派彩、玩家盈虧。
- 統一 40px 篩選控制項與上下共用的 1–7 欄網格（按主畫面可用寬度自動調整，包含選單展開／收合）；日期標籤統一在上方，快捷下拉選單與區間按鈕各佔一欄，與其他欄位共用網格；同一天只顯示一次，窄欄位的跨日區間以月日顯示、年份標示在上方，完整區間保留於提示與日期選擇器；下拉箭頭和文字保留對稱留白。日期區間使用錨定日曆元件，不遮住整頁。表頭與資料不強制換行，欄位過多可橫向捲動；工作分頁超長提供全文提示。
- 深淺外觀與手機版排版。
- 內容區隨可用視窗寬度延伸，桌面左右各留 32px；Header 與內容齊線。表格高度依剩餘視窗計算，寬螢幕可直接顯示更多欄與列，字體與控制項大小不放大。
- 表頭名稱、排序與篩選緊密分組並置中，左右各 20px 留白；欄寬依目前語系文字的實際字寬調整，金額內容維持右對齊。預設凍結至玩家 ID，保留自行調整。表格比視窗窄時延展欄寬，凍結偏移依實際欄寬重新計算。
- Active 與主要操作統一品牌綠；資訊圖示以藍、紫、琥珀輔助識別。正值盈虧／派彩維持綠色，負值紅色，零值與成本中性。所有資訊摘要有語意圖示，合計列統一綠底。

- 遊戲統計採左右獨立堆疊，佔比卡片依內容收合高度，圖表與圖例置中並統一留白，營運排行緊接下方；窄畫面切回單欄閱讀順序。
- 遊戲統計預設視覺總覽：去重玩家曲線、遊玩筆數／投注額佔比圓環圖、投注／派彩趨勢、遊戲營運排行，可切換傳統表格。曲線為有投注記錄的玩家，並非即時在線人數。
- 玩家詳情增加總盈利及總虧損，分別加總正數及負數淨盈虧，兩者相加等於區間淨盈虧。
- 分頁採檔案式外觀。子選單 220ms 從左側滑入、180ms 向左收回，詳情首次 260ms 從右側滑入、220ms 向右關閉，後續鑽取 190ms 短距離滑動；動畫可中斷，支援減少動態與降低透明度設定。

## 逐層詳情與視覺切換

從報表工具列的「機構總覽」，或供應商／站點欄位，可依序查看 **遊戲商 → 包網商 → 現金網 → 玩家 → 遊戲 → 投注明細**。機構層級以可點擊的圖示關係卡片連接，每層保留返回上一層，移除重複的詳情標題，機構與玩家可切換「視覺摘要／傳統表格」，金額與範圍一致。

- 六個包網商、18 個現金網、132 位玩家；每位玩家只屬於一個現金網，逐層加總不重複。
- 18 款虛構遊戲：4 款電子闖關、5 款老虎機、3 款捕魚及 6 款棋牌。相同家族共用示範規則與六張分類封面，正方形、12px 圓角；卡片呈現投注佔比、玩家盈虧與獎池派彩。
- 時段圖依記錄的每小時投注額計算，並非隨機製造的 KPI。尚無登入、註冊、留存等資料，因此不顯示這些指標。
- 投注派彩差額＝投注−派彩，未扣分潤與營運費用，不能當成機構實際收益。
- 篩選標籤與輸入框相距 6px，控制項維持 40px；長字保留換行或全文提示。

## 子彈費率與獎池口徑

捕魚同一批次包含 Lv.1 至 Lv.5 五級子彈，逐發保存基礎面額、炮倍、當時費率、實扣金額、來源及扣款 ID，並記錄級距切換後首發 ID。以原始 F001 為例：30×1＋20×1.5＋10×2＋20×3＋10×4＝180 USDT，再加一次道具費 20＝200；10 發免費彈的參考面值 40 不計入投注。

九款遊戲示範可配置獎池，九款未配置。獎池有 ID、級別、規則版本、觸發來源、父事件、提撥、前後餘額、獎金、交易及入帳狀態；區分未配置、未觸發、已入帳。示範提撥率為 2%，已含在投注內，並非額外扣款。一般派彩與獎池派彩分列，總派彩只算一次。費率、獎池門檻與棋牌特殊規則均為 **Demo 規則提案**，正式規則以供應商 API 為準。

[射擊及首領玩法參考：JILI Bombing Fish](https://jiligames.com/PlusIntro/20?showGame=true)。參考只用於玩法事件規劃，並未把示範 USDT 費率當成供應商真實設定。

## 模擬資料

日期為 **2026/10/15，UTC+8**，共 1,200 筆記錄、132 位玩家、18 款遊戲；四類投注報表各 300 筆，玩家遊戲報表有 477 筆「玩家 × 遊戲」彙總。

| 項目 | USDT |
| --- | ---: |
| 實扣投注 | 291,350.00 |
| 結算派彩 | 440,560.00 |
| 玩家淨盈虧 | +149,210.00 |

本例派彩包含返還本金，費用與退款為 0。統計中的「投注派彩差額」採投注減派彩，因此符號與玩家淨盈虧相反。合計為全部篩選結果，玩家數與遊戲數去重；倍率、餘額、累積盈虧及排行不相加。

全部為示範資料，未接正式帳號、遊戲供應商或資金 API。老虎機金額沿用提供的截圖範例；補充事件、關聯與其他玩法為模擬情境。其他業務主選單保留導覽示意；玩家管理的子選單依設計要求留空。

## 本機預覽與驗證

    npm start

開啟 http://127.0.0.1:4173/。也可以使用任意靜態 HTTP server。

    npm test

測試涵蓋七種報表金額一致性、玩家 ID 關聯、合計與去重、篩選、空資料、逐發成本／獎金、錢包餘額、CSV 精度、數值排序、語系欄位完整性與舊分頁設定轉換。

    npm run build:data

可由保留的 21 筆種子資料，重建相同的 1,200 筆模擬記錄；原始 400 筆的金額、玩家與站點不變。

## GitHub Pages

在 GitHub 的 **Settings → Pages** 選擇 **Deploy from a branch → main → / (root)**。後續更新 main 即會重新部署。

所有頁面使用 hash 路由，例如 /#fishing、/#slots、/#stats，重新整理不需要額外的伺服器路由設定。

## 檔案

- index.html：共用頁面框架。
- styles.css、ui-theme.css：原始版型與共用材質、層級、響應式樣式。
- ui-icons.js、assets/rr-logo.svg：語意圖示與使用者提供的品牌 SVG。
- analytics.js、statistics-view.js：統計計算與視覺總覽。
- date-picker.js、motion.js：錨定日曆與可中斷動態。
- app.js：導覽、工作分頁、表格與玩法明細。
- assistant.js、filter-multi.js：資料助理檢索與共用複選元件。
- core.js：資料篩選、計算、排序、CSV 與明細模型。
- i18n.js、data/locales.tsv：共用簡譯字典與語系切換。
- data/demo-data.json：共用模擬資料與報表欄位定義。
- game-catalog.js：18 款遊戲、家族、分類封面與獎池配置。
- data/seed-data.json、scripts/build-demo-data.mjs：可重現的資料產生器。
- detail-views.js：共用封面、遊戲卡片、時段圖與玩法指標。
- assets/games/：內建 imagegen 生成的原創封面；prompts.json 保存完整提示詞與輸出路徑。
- assets/figma/：從對應 Figma 圖層下載的原始 SVG／頭像素材。
- tests/：資料與業務計算驗證。
